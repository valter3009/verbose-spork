# 🚀 CryptoBot - Telegram Бот для Криптотрейдеров

Профессиональный Telegram бот для отслеживания криптовалют, управления портфолио и настройки ценовых алертов. Создан для сотен тысяч пользователей ежедневно.

> **⚡ Хотите быстро запустить?** См. [QUICKSTART.md](QUICKSTART.md) - запуск за 1 минуту!

## ✨ Основные Возможности

- 💰 **Отслеживание цен в реальном времени** - мгновенное получение актуальных цен криптовалют
- 📊 **Топ криптовалют** - список лучших монет по капитализации
- 🔥 **Трендовые монеты** - самые популярные криптовалюты сегодня
- 💼 **Управление портфолио** - отслеживайте свои инвестиции и прибыль/убытки
- 🔔 **Ценовые алерты** - получайте уведомления при достижении целевой цены
- 💱 **Конвертер валют** - конвертация между криптовалютами
- 📈 **Графики цен** - визуализация изменения цен
- ℹ️ **Информация о монетах** - подробная информация о криптовалютах

## 📋 Требования

- Docker и Docker Compose
- Git
- Telegram Bot Token (уже включен в проект)

## 🚀 Быстрый Старт

### 1. Клонирование Репозитория

```bash
git clone https://github.com/valter3009/verbose-spork.git
cd verbose-spork
```

### 2. Настройка Переменных Окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите ваш Telegram Bot Token:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_здесь
DATABASE_PATH=data/crypto_bot.db
```

**Примечание:** В проекте уже есть `.env` файл с вашим токеном, можете использовать его.

### 3. Запуск с Docker Compose (Рекомендуется)

```bash
# Сборка и запуск
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down

# Перезапуск
docker-compose restart
```

### 4. Альтернативный Запуск с Docker

```bash
# Сборка образа
docker build -t crypto-telegram-bot .

# Запуск контейнера
docker run -d \
  --name crypto-bot \
  --restart unless-stopped \
  -e TELEGRAM_BOT_TOKEN=ваш_токен_здесь \
  -v $(pwd)/data:/app/data \
  crypto-telegram-bot

# Просмотр логов
docker logs -f crypto-bot

# Остановка
docker stop crypto-bot

# Удаление контейнера
docker rm crypto-bot
```

## 📱 Использование Бота

### Основные Команды

- `/start` - Запуск бота и приветствие
- `/help` - Справка по всем командам
- `/price <монета>` - Узнать цену криптовалюты
- `/top [количество]` - Топ криптовалют (по умолчанию 10)
- `/trending` - Трендовые криптовалюты
- `/info <монета>` - Подробная информация о монете

### Управление Портфолио

```
/portfolio - Показать текущее портфолио
/portfolio add <монета> <количество> <цена_покупки> - Добавить в портфолио
/portfolio remove <id> - Удалить из портфолио
/portfolio clear - Очистить портфолио
```

**Примеры:**
```
/portfolio add bitcoin 0.5 30000
/portfolio add ethereum 2 2000
/portfolio remove 1
```

### Ценовые Алерты

```
/alert - Показать все алерты
/alert add <монета> <above|below> <цена> - Создать алерт
/alert remove <id> - Удалить алерт
```

**Примеры:**
```
/alert add bitcoin above 50000
/alert add ethereum below 2000
/alert remove 1
```

### Дополнительные Команды

```
/convert <количество> <из_монеты> <в_монету> - Конвертация
/chart <монета> [дней] - График цены
```

**Примеры:**
```
/price bitcoin
/price BTC
/price ethereum
/convert 1 bitcoin ethereum
/chart bitcoin 30
/top 20
```

## 🔧 Технологии

- **Python 3.11** - Основной язык программирования
- **python-telegram-bot** - Telegram Bot API
- **pycoingecko** - CoinGecko API для данных о криптовалютах

## ⚙️ Настройки

Вы можете изменить настройки в `src/config/config.py`:

- `ALERT_CHECK_INTERVAL` - Интервал проверки алертов (по умолчанию 5 минут)
- `PRICE_CACHE_DURATION` - Длительность кеширования цен (60 секунд)
- `MAX_PORTFOLIO_ITEMS` - Максимум позиций в портфолио (50)
- `MAX_ALERTS_PER_USER` - Максимум алертов на пользователя (20)

## 🚨 Устранение Проблем

### Бот не отвечает

1. Проверьте логи: `docker-compose logs -f`
2. Убедитесь что контейнер запущен: `docker-compose ps`
3. Проверьте правильность токена в `.env`

### Ошибки API

- CoinGecko API имеет лимит запросов (50 запросов/минуту для бесплатного тарифа)
- Бот автоматически кеширует данные для снижения нагрузки

### База данных

Если нужно сбросить базу данных:

```bash
rm -rf data/crypto_bot.db
docker-compose restart
```

## 📈 Масштабирование

Для обработки сотен тысяч пользователей:

1. **Увеличьте ресурсы контейнера** в `docker-compose.yml`
2. **Используйте Redis** для кеширования вместо встроенного
3. **Переключитесь на PostgreSQL** для лучшей производительности
4. **Настройте мониторинг** (Prometheus + Grafana)
5. **Используйте webhook** вместо polling для Telegram API
